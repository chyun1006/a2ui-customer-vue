# 消息发送

## 需求背景

- v1 版本已经实现了根据a2ui json展示页面的功能
- 现在需要实现用户提问后，后端会返回一个a2ui 的json，前端需要渲染这个json
- 整个过程就是一问一答的过程。
- 新增一个路由 /chat，此页面的局部实现参考[text](resources/App.tsx)这个页面的实现
- 用户点击发送后调后后端接口，接口响应后根据接口返回的a2ui json渲染页面

- 后端接口
- **baseURl**:http://10.30.32.110:8080
- **interface**: /api/chat
- **method**: POST
- **request**:
  ```json
  {
    "message": "用户输入的消息",
    "sessionId": "会话ID",
    "workNo": "工号"
  }
  ```
- **response**:

```json
{
  "success": true,
  "a2ui": "a2ui json"
}
```
